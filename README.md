# Santanu Ojha
### Researcher in Trustworthy ML & AI Security

I am a developer and researcher focused on building secure, interpretable, and robust machine learning systems. With hands-on experience at the **Defence Research and Development Organisation (DRDO)**, I specialize in applying Explainable AI (XAI) and cutting-edge deep learning architectures to solve complex cybersecurity and computer vision challenges.

Currently, I am actively seeking Master's program opportunities to contribute to research in Trustworthy ML, AI privacy, and intelligent system security.

*   **AI for Cybersecurity (Network Intrusion Detection)**

## 🚀 Highlighted Research & Projects

*   **[Explainable AI for Intrusion Detection (XAI-IDS)](https://github.com/SantanuOjha/Explainable-AI-IDS)**
    *Developed a hierarchical network intrusion detection system utilizing Explainable AI. This framework identifies anomalous network behavior and potential breaches while providing transparent, interpretable decision-making metrics for security analysts.*

*   **[Deep Variational Models for Collaborative Filtering](https://github.com/SantanuOjha/Collaborative-Filtering-with-Deep-Variational-Models)**
    *Implemented deep generative architectures to model complex user-item interactions. This project explores variational inference techniques to improve the robustness and accuracy of recommendation systems under data sparsity.*

*   **[Explainable Computer Vision (XAI-CV)](https://github.com/SantanuOjha/Explainable_CV)**
    *Applied interpretability techniques to deep learning vision models. The project focuses on model transparency, extracting visual explanations and saliency maps to understand how convolutional networks arrive at specific classifications.*

*   **[Core Intrusion Detection System (IDS)](https://github.com/SantanuOjha/IDS-Intrusion-Detection-System-)**
    *Engineered a foundational machine learning pipeline for network threat detection, focusing on processing high-dimensional network traffic data to classify malicious activities with high precision.*
